# Manchester United AI Analyst

## Tech Stack
- Java 25
- Spring Boot 4
- PostgreSQL 17
- Flyway
- React and TypeScript
- Redis
- API-Football

## Development Rules
- Inspect existing code before editing.
- Reuse existing architecture.
- Never modify applied Flyway migrations.
- Never invent football statistics.
- Keep MOCK and LIVE data isolated.
- Do not hardcode secrets.
- Do not commit or push automatically.

## Verification
- Run Maven tests after backend changes.
- Run frontend build after frontend changes.
- Check Git diff before reporting completion.
